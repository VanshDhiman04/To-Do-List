# ☀️ Daylight — To-Do List

A clean, modern, and responsive To-Do List web application designed to help you organize daily tasks, prioritize your work, and track your productivity.

## ✨ Features

- **Add Tasks:** Quickly create tasks with a simple input form.
- **Task Priorities:** Categorize tasks as High, Medium, or Low priority.
- **Due Dates:** Assign deadlines and identify overdue tasks.
- **Task Management:** Mark tasks as completed or delete them when no longer needed.
- **Smart Filters:** View all tasks, today's tasks, upcoming tasks, and completed tasks.
- **Search Tasks:** Find tasks quickly using the search bar.
- **Sorting Options:** Sort tasks by creation order, due date, priority, or alphabetical order.
- **Progress Tracking:** View your completion percentage and remaining task count.
- **Persistent Storage:** Tasks are saved in your browser's local storage.
- **Responsive UI:** Designed to work on desktop and mobile screens.
- **Nature-Inspired Design:** Scenic background, clean layout, and soft green accents.

## 🛠️ Technologies Used

- **HTML5** — Structure and content
- **CSS3** — Styling, layout, animations, and responsive design
- **JavaScript** — Task management and interactive functionality
- **Local Storage** — Saving tasks in the browser

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/VanshDhiman04/To-Do-List.git
```

### 2. Open the project

```bash
cd To-Do-List
```

### 3. Run the application

Open `index.html` in your browser.

Alternatively, open the project in Visual Studio Code and use the **Live Server** extension.

No package installation or build process is required.
